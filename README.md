# Athene

An Android app for learning a foreign language from English: Spanish, French, German, Dutch, Italian or Japanese.
It works offline and has no accounts, ads or backend.

- **Lessons on a path.** Each lesson introduces six words, then practises them: pick the meaning, match pairs,
  build sentences from word tiles, type the word, listen, and say it aloud.
- **Reviews that are timed.** Everything you meet joins a spaced-repetition queue and comes back when it is about
  to be forgotten.
- **Sentences you can read.** A sentence only appears once every word in it has been taught. Tap any word for its
  meaning.
- **Speech from the device.** Text-to-speech and speech recognition come from Android itself; no audio is bundled.

Each course is about 1,500 of the most frequent words and 1,000 sentences, after a short unit of survival phrases.
Japanese adds hiragana and katakana units, kana readings, and exercises that never need a Japanese keyboard.

## Build

Needs JDK 17 and the Android SDK (platform 36).

```sh
./gradlew assembleDebug        # debug APK
./gradlew test                 # unit tests, including checks on the shipped course database
./gradlew installDebug         # install on the connected device or emulator
```

Set `ANDROID_SERIAL` (for example `emulator-5554`) when more than one device is attached.

### Release

Release signing is read from `keystore.properties` in the project root, which is not in version control:

```properties
storeFile=athene-upload.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

Create the key once with
`keytool -genkeypair -v -keystore athene-upload.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000`,
then:

```sh
./gradlew assembleRelease      # APK in app/build/outputs/apk/release/
./gradlew bundleRelease        # AAB for Google Play
```

Without `keystore.properties` the release build still runs but is left unsigned. A debug build must be
uninstalled before a release build can be installed, because they are signed with different keys.
Raise `versionCode` in `app/build.gradle.kts` for every upload.

## Course content

`app/src/main/assets/content.db` is generated by `tools/build_content.py` (Python 3, standard library only) and
checked in. To rebuild it:

```sh
python3 tools/build_content.py           # every language; downloads about 600 MB into tools/.cache/ the first time
python3 tools/build_content.py es fr     # only some languages (the database then holds only those)
```

How a course is made:

1. Words are ranked by how often they occur in film subtitles, counting every inflected form under its
   dictionary word (`tengo` counts for `tener`).
2. The top 1,500 are cut into lessons of six. Meanings come from Wiktionary.
3. Each lesson gets up to four Tatoeba sentences whose words have all been taught by then.

Automatic meanings are weakest for the most common words, so those are written by hand in
`tools/overrides/<language>.tsv` (`word<TAB>meaning`; `-` drops a word, `=lemma` files a form under its
dictionary word). `--explain word1,word2` prints why a word ranks where it does.

Japanese is built from Tatoeba's word-by-word index of its Japanese sentences and from JMdict instead, because
Japanese is written without spaces.

When the content changes, raise `DB_VERSION` in `tools/build_content.py`, `version` in
`app/src/main/java/io/github/athene/data/Content.kt` and the expected value in `ContentDbTest`, or existing
installs keep their old copy. Learner progress lives in a separate database and is keyed by stable item ids, so
it survives a content update.

## Code map

```
app/src/main/java/io/github/athene/
  data/      Content.kt (read-only course), User.kt (progress, schedule, XP), Settings.kt
  srs/       Scheduler.kt: spaced repetition and streaks
  lesson/    Exercise.kt: exercise types and the generator; Grader.kt: answer checking
  speech/    Speaker.kt (text-to-speech), Listener.kt (speech recognition)
  ui/        home (path), lesson (player), words, settings, onboarding, theme
tools/       build_content.py, overrides/, phrases.json
```
